逐条解读

1. Gemini 4 Neon 发布，Gemini 4 系列价格结构进一步复杂化

发生了什么：2026-11-18，Google DeepMind 发布 Gemini 4 Neon。据 Simon Willison 同日整理，当前三档价格为 Neon（$3 / 百万输入 token，$15 / 百万输出）、Carbon（$2 / $10，处于半价期）、Hydrogen（$1.50 / $7.50）；Carbon 将于 12 月 1 日恢复原价 $4 / $20。Neon 在宣传材料中未提及 Argon 这一档。

意味着什么：模型厂商正在用"同代多档 + 限时折扣"制造价格迷雾，短期比价几乎不可行。对使用者来说，真正的决策点不是"哪个最强"，而是"12 月 1 日之后哪个性价比成立"。

对你的影响：本周不用管具体型号。等 12 月 1 日价格落定后，花 10 分钟把三档价格抄进你的学习笔记，作为 W12「评估与成本」的素材。

2. GPT-6.2 Astra 与 Sol：更便宜，但体验评价分裂

发生了什么：2026-11-17 前后，GPT-6.2 Astra 与 6.2 Sol 发布。Latent Space 的 AINews 称 Astra 是"第 2 名前沿模型"，比前代"更好且便宜 20%–600%"，但早期测试者对实际使用体验存在分歧；该文判断 6.2 Sol 更可能成为主力工作模型。具体基准分数与定价细节未核实。

意味着什么：降价幅度是这轮竞争的主战场，能力差距在收窄。"便宜 20%–600%"这种区间本身说明不同任务上的成本差异极大，不能当成统一折扣理解。

对你的影响：与你无关，知道即可。你现在还没有到需要按 token 成本选模型的阶段。

3. 腾讯元宝 × KCL：首个基于群聊的 Agent 记忆基准

发生了什么：2026-11-21，量子位报道腾讯元宝与 KCL 联合发布一个 Agent 记忆基准，用 8 万条群聊消息构建考卷。具体评测维度与榜单结果未核实（原文摘要为空）。

意味着什么：Agent 的"长期记忆"开始有了可比较的评测方式，而不是各家自说自话。这类基准通常领先于产品能力，说明记忆仍是未解决的短板。

对你的影响：与你无关，知道即可。等你在 W10 学 Agent 时再回来看这条。

4. Gemini API 上线 Tool Retrieval

发生了什么：2026-11-19，Google 在 Gemini API 中引入 Tool Retrieval。官方博客标题确认该功能存在，但摘要内容缺失，具体机制、支持的模型范围与是否额外计费未核实。

意味着什么：当工具数量变多时，"先检索出该用哪个工具"成为独立环节，这是 Agent 工程化的典型信号——工具不再靠全量塞进 prompt。

对你的影响：与你无关，知道即可。这是 W10–W11 的内容，现在看只会增加噪音。

5. 形式化验证（Lean）被当作对抗"AI 垃圾输出"的武器

发生了什么：2026-11-20，Latent Space 发文讨论用数学证明软件正确性，指出过去需要专家手工完成，现在 AI + Lean 正在把这一过程自动化。同期 Simon Willison 引用了数学家 Ravi Vakil 的说法：一份关于广义黎曼猜想的证明"全部由人类完成，没有 AI"。

意味着什么：同一周内，"AI 辅助证明"和"纯人类证明"被并列讨论，说明 AI 在数学上的角色仍有争议，但"用形式化验证给 AI 输出上保险"这条路正在被认真对待。这是能力边界的一次明确划线：可验证的领域，AI 输出可信度能被机器检查；不可验证的领域不能。

对你的影响：记住这个区分——"输出能不能被机器自动检验"是判断一个 AI 任务风险高低的第一问。这一条可以直接写进你 W1 的笔记。

本周该记住的一个判断

这一周真正的信号不是某个模型更强，而是价格结构和能力评价同时变得不可靠：同代模型分三档、限时折扣、涨价日期错位，早期测试者对同一模型的体验评价互相矛盾。在这种环境下，追新没有收益，唯一稳的动作是把自己的任务固定下来，用同一批输入去测，看哪个模型在你的场景里稳定。这也正好是你 14 周计划里 W3「怎么判断模型好坏」要解决的问题——现在提前知道"榜单不可信"这件事，比记住任何型号都有用。
