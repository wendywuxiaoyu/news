## 逐条解读

### 1. Gemini 4 家族定价混乱，12 月 1 日 Carbon / Argon 价格翻倍

**发生了什么**：11 月 10 日 Gemini 4 Carbon 向所有用户开放，11 月 12 日又发布更便宜的 Gemini 4 Hydrogen。据 Simon Willison 整理的价目：Carbon 与 Argon 当前均为输入 $2 / 输出 $10（每百万 token），12 月 1 日起涨至 $4 / $20；Hydrogen 为输入 $1.50 / 输出 $7.50。Carbon 与 Argon 同价但定位不同，Google 称 Argon 每轮消耗 token 更少。

**意味着什么**：同一家厂商在同一周内出现"同价不同模型 + 限时低价 + 即将翻倍"的组合，说明模型定价已进入促销式波动期，任何"单价对比表"的保质期都很短。对个人用户而言，真正的成本变量是"每任务消耗多少 token"，而不是标价。

**对你的影响**：与你学习计划的关联——W1「AI 的地形与边界」里，把"模型价格是动态的、会促销也会涨价"作为一条边界常识记下即可，不要现在去比价或选型。W12「评估与成本」才是认真算这笔账的时候。

### 2. 决策模型成为独立品类：Jev、OpenAI、Gemini 三家同台

**发生了什么**：11 月 11 日 Google 推出 Gemini Decisions API（模型名 Gemini Decision 1），支持是/否、多选、评分三种问法，定价为输入 $0.10 / 百万 token、输出免费。Simon Willison 指出它与 Jev 的接口几乎一致，甚至沿用了 Jev 的 "Noul" 术语；Jev 仍最便宜（$0.042 / 百万），OpenAI 的 GPT-6 Luna 决策模型同价 $0.10，Gemini 则覆盖文本、图像、音频、视频、PDF 全模态。他在视频测试中的具体结论未在摘要中完整给出，**未核实**。

**意味着什么**：出现了一类"只做判断、不做生成"的模型，把"分类/打分"从通用大模型里拆出来单独计价。这说明能力边界正在细分——不是所有任务都需要一个会写文章的模型。

**对你的影响**：与你学习计划的关联——W1 只需建立一个概念：模型不只有"聊天"一种形态。具体怎么用，等 W10「Agent 与三种改造方式的决策」再回来看这条。

### 3. ChatGPT Wallet：Agent 可在用户批准下完成购买

**发生了什么**：11 月 13 日 OpenAI 发布 ChatGPT Wallet，定位是让 ChatGPT Work、Codex 和 dots 中的 Agent 在用户批准的前提下完成购买，并沿用现有银行卡保护机制。具体支持哪些商户、地区与限额，摘要中未说明，**未核实**。

**意味着什么**：这是本周最明确的"新形态"信号——Agent 的权限从"读和写"扩展到"付钱"，人机协作的确认环节被产品化。但支付类能力的落地通常伴随严格的地域与合规限制，短期内对普通用户的可及性存疑。

**对你的影响**：与你学习计划的关联——W1 记一句"Agent 已经能碰钱了"作为边界认知即可。真正需要你判断权限设计，是 W10 之后的事。

### 4. AWS 官方本地模拟器 aws-emulator：三周 29,684 次提交，由 Agent 集群写成

**发生了什么**：11 月 11 日 Simon Willison 提到 AWS 发布官方本地模拟器 aws-emulator，用 Rust 编写，可在不申请付费 API key 的情况下本地测试多项 AWS 服务；项目前三周产生 29,684 次提交，作者称由大量 Agent 协作完成。macOS / Windows 上目前需要 Docker。

**意味着什么**：这条的价值不在 AWS，而在"近 3 万次提交 / 3 周"这个量级——它说明 Agent 驱动的工程产出已经进入可交付真实基础设施的阶段。这是能力边界的一次实证，而非营销话术。

**对你的影响**：与你学习计划的关联——W1 不需要碰它。但把"Agent 能规模化产出可用代码"作为你 14 周计划的一个背景事实记住，它会解释为什么 W10 之后的内容值得认真学。

### 5. NaiveAI 宣称 2,100 tokens/秒，实测编码质量与 DeepSeek 相当

**发生了什么**：11 月 10 日 Latent Space 的实测文章称，NaiveAI 有可能登顶 Artificial Analysis 的速度榜，宣称 2,100 tokens/秒；作者手工测试认为其编码质量与 DeepSeek 相当。具体测试方法与样本量摘要未披露，**未核实**。

**意味着什么**：速度正在成为独立竞争维度，但"快"与"好"目前仍是两条曲线。对使用者来说，速度只有在长输出或高频调用场景才转化为真实收益。

**对你的影响**：与你学习计划的关联——W1 不用管。等 W3「怎么判断模型好坏」时，这条可以作为"榜单数字不等于实际体验"的案例回看。

## 本周该记住的一个判断

这一周的信息密度很高，但对你 W1 真正有用的只有一件事：**AI 的能力边界正在从"生成内容"向"做判断"和"执行动作"两头扩张**——决策模型负责判断，Wallet 和 Agent 负责执行。这意味着你后面 13 周学的不是"怎么跟聊天框说话"，而是"怎么给一个会判断、会动手的系统划边界"。价格、榜单、CEO 变动这些噪音，本周一律不占你的注意力预算。
