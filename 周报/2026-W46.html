AI 周报 · 2026-11-06 至 2026-11-14

本周三件事

  1. Gemini 4 家族铺开，但定价结构复杂且 12 月 1 日翻倍——Carbon/Argon 现价 $2/$10 每百万 token，12 月起变 $4/$20；Hydrogen 更便宜（$1.5/$7.5）。所以呢：现在不是锁定长期成本的好时机，先别为"便宜"做架构决策。
  2. "决策模型"成为一个独立品类——Google 的 Gemini Decisions API 与 Jev、OpenAI 的决策模型同台，输出几乎免费（10 美分/百万输入，输出免费）。所以呢：以后"是/否、多选、打分"这类判断不必再走通用大模型，成本会掉一个量级。
  3. ChatGPT Wallet 上线——让 ChatGPT Work、Codex、dots 里的 agent 在用户批准下完成支付。所以呢：agent 从"给建议"跨到"能花钱"，这是形态变化，但对你现在无关。

逐条解读

1. Gemini 4 家族定价：Carbon / Argon / Hydrogen

发生了什么 2026-11-12，Google 上线 Gemini 4 Hydrogen，是家族里最便宜的一档：输入 $1.50 / 缓存输入 $0.075 / 输出 $7.50（每百万 token）。Carbon 与 Argon 同价 $2 / $10，且两者都将在 2026-12-01 翻倍至 $4 / $20。Google 称 Argon 与 Carbon 同价但"响应更快、每轮 token 消耗更少"。

意味着什么 同一家族里出现"同价不同效率"的型号，说明厂商开始用 token 消耗而非单价来区分产品——你比较成本时不能只看价目表。12 月 1 日的翻倍是明确的涨价信号，说明当前价格是推广价而非长期价。

对你的影响 与你学习计划的关联：W1 只需记住"模型有价格档位、价格会变"这个事实，不必现在算账。具体动作：在你的笔记里建一行"模型价格表"，只记型号、日期、单价三列，12 月 1 日后再回填一次，用来观察价格变动——这是 W12「评估与成本」的素材，现在只做记录不做判断。

2. 决策模型（Decision Models）成为独立 API 品类

发生了什么 2026-11-11，Google 发布 Gemini Decisions API（模型名 Gemini Decision 1），支持三类问题：是/否、多选、按 rubric 打分，并沿用 Jev 的 "Noul" 术语指代是/否问题。定价为每百万输入 token 10 美分、输出免费；Jev 更便宜，为每百万 4.2 美分。Jev 仅支持文本与 JSON，OpenAI 的决策模型支持文本与图像，Gemini Decision 1 覆盖文本、图像、音频、视频、PDF。

意味着什么 "让模型做一个受限判断"和"让模型生成内容"被拆成了两种产品，前者便宜到可以忽略成本。这意味着很多原本用通用大模型硬做的分类、审核、打分任务，未来会迁移到专用小接口上。

对你的影响 与你学习计划的关联：这条直接对应 W3「怎么判断模型好坏」——你会遇到"同一个任务，用通用模型还是专用决策模型"的选择题。具体动作：现在只在笔记里记一句"决策模型 = 受限输出 + 极低成本"，不要动手试；等 W3 学完评估方法后，再拿一个你自己的真实判断任务（比如"这封邮件要不要今天回"）做对比实验。

3. ChatGPT Wallet：agent 获得支付能力

发生了什么 2026-11-13，OpenAI 发布 ChatGPT Wallet，定位是让 ChatGPT Work、Codex、dots 中的 agent 在用户批准下完成购买，并沿用现有银行卡保护机制。同期 OpenAI 还发布了多项企业客户案例（Amplitude、Gondola、Holiday Extras、Shield），均围绕 Codex 与 agent 提效，未披露统一的可比数字。

意味着什么 这是形态变化而非能力变化：agent 的边界从"读和写"扩展到"交易"，但关键设计是"用户批准"这一环仍在。企业案例密集发布说明 agent 的商业叙事正从 demo 转向采购。

对你的影响 与你学习计划的关联：W10「Agent 与三种改造方式的决策」会讨论 agent 的权限边界，这条是未来的案例。具体动作：现在不做任何事，也不要开通任何支付相关功能；只在 W10 那周的笔记里预留一行"agent 能执行的动作范围"。

4. NaiveAI：2,100 tokens/秒的速度宣称

发生了什么 2026-11-10，Latent Space 对 NaiveAI 做了上手测试，该产品宣称可达每秒 2,100 tokens，可能冲击 Artificial Analysis 的速度榜；测试结论是其编码质量"与 DeepSeek 相当"。具体基准分数与测试方法未在摘要中给出，未核实。

意味着什么 速度正在成为独立卖点，但"快"和"好"在这类产品上是分离的——报道自己就说质量只是"持平"而非领先。速度提升改变的是交互形态（能不能边写边等），不是能力上限。

对你的影响 与你学习计划的关联：W1 的主题是"地形与边界"，速度属于地形的一部分，但这条信息密度低。具体动作：知道即可，不花时间；等 W3 学了评估方法，再回头看这类"速度宣称"该怎么验证。

5. 黄仁勋辞任英伟达 CEO（多源报道）

发生了什么 2026-11-13，Latent Space 与量子位均报道黄仁勋在领导英伟达 33 年后辞任，Colette Kress 出任临时 CEO，报道提及市值大幅蒸发（量子位标题称"超 3 万亿"，币种与口径未核实）。原始条目未提供官方公告链接。

意味着什么 这是行业结构性事件，但两个来源都是二手转述，缺少一手信源。对"你怎么用 AI"没有直接传导路径——芯片供应、模型价格、产品能力都不会在一周内因此改变。

对你的影响 与你无关，知道即可。不要基于这条做任何学习计划或工具选择的调整；如果后续出现官方公告与具体产品影响，再单独评估。

本周该记住的一个判断

这一周真正的信号不是某个模型更强，而是"判断"这件事正在被单独定价。当是/否、多选、打分这类受限任务的价格降到每百万 token 几美分，很多过去"必须用大模型硬扛"的场景会重新分配——贵的模型留给生成和推理，便宜的专用接口留给分类和筛选。对你现在的位置来说，这个判断的价值不在于马上用，而在于它给了你一个观察框架：以后看到任何 AI 产品，先问它做的是"生成"还是"判断"，这两类东西的成本曲线和可靠性特征完全不同。你在 W1 只需要把这个二分法记住，后面 W3 的评估、W12 的成本都会回到它上面。
