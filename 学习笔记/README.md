# 学习笔记 · 说明

## 笔记写在哪

**写在 Notion 里**，不要写在本地。原因很简单：你换设备学习，Notion 手机、平板、电脑都能开。

## 位置规则（只有两条）

1. 在「AI学习成长记」下面，任意一个**标题里带「笔记」两个字**的页面（你现在用的是「小雨的笔记」）
2. 每个主题建一个**子页面**，标题写 `Wxx 主题`，比如「W1 什么是大模型」

```
AI学习成长记
├─ 小雨的笔记              ← 标题带「笔记」就会被识别
│   ├─ W1 什么是大模型      ← 你写内容的地方
│   └─ W2 机器学习在干什么
├─ AI 周报 · 2026-W46
└─ AI 周报 · 2026-W47
```

系统会读这个页面下**最近 4–8 天**有内容更新的子页面。标题写什么都行，只要**有正文**——只有标题、没有内容的页面会被忽略。

## 每周记什么

不用写日记。三句话，加起来 200 字：

1. **我做了什么**（动词开头：「用 sklearn 跑了鸢尾花分类」）
2. **哪里卡住了**（越具体越好：「不懂梯度下降」是废话，「不知道学习率设多少合适」才有用）
3. **我怎么理解的**（用你自己的话，比喻土一点没关系）

## 什么时候读

| 时间 | 干什么 |
|---|---|
| 周一 07:00 | 周报末尾附「上周进度诊断」 |
| **周三 20:00** | 复盘邮件：进度判定 / 缺口 / 下一步 |
| **周日 20:00** | 同上，另加一份归档 |

**四天没写笔记，周三或周日会收到一封提醒邮件**，里面带本周任务卡。
