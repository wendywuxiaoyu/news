# 学习笔记 · 说明

## 笔记写在哪

**写在 Notion 里**，不要写在本地。

原因：你换设备学习，Notion 手机、平板、电脑都能打开，本地文件不行。

## 位置要求（重要）

在 Notion 的「AI学习成长记」页面下，建一个子页面，名字叫 **「学习笔记」**。

```
AI学习成长记
├─ 学习笔记              ← 必须是这个名字
│   ├─ W1 什么是大模型      ← 每周/每个主题一个子页面
│   ├─ W1 我的 5 个翻车案例
│   └─ ...
├─ AI 周报 · 2026-W46
└─ AI 周报 · 2026-W47
```

「学习笔记」这一层是**约定**：每周一的自动化会去找这个名字的页面，读它下面的子页面，对照本周任务判断你的进度。名字不对就找不到，会跳过进度诊断。

## 每周记什么

不用写日记。每周只要三样东西，加起来 200 字就够：

1. **我做了什么**（动词开头，比如「用 sklearn 跑了鸢尾花分类」）
2. **哪里卡住了**（越具体越好，「不懂梯度下降」是废话，「不知道学习率设多少合适」才有用）
3. **我怎么理解的**（用你自己的话，哪怕比喻很土）

## 为什么笔记会被读

每周一早上，系统会读你最近一周的笔记，对照本周任务，在邮件末尾给出：

- 进度判定（达标 / 部分完成 / 滞后）
- 关键缺口
- 本周建议

**它只会根据你写的判断，不会猜。** 你写得越具体，反馈越有用。一周没写，就跳过诊断。

## 本地这个文件夹是干嘛的

只放模板和说明。真正的笔记在 Notion，这里不用填。
